# Tankfire Simulation (ACOS Course)

Базовый проект для курса "Архитектура операционных систем" и смежных дисциплин. 
Реализует консольную симуляцию артиллерийского огня по движущимся целям (танкам) на прямоугольном поле с препятствиями.

Проект построен модульно и служит фундаментом для последующих лабораторных работ, посвященных многопоточности, межпроцессному взаимодействию и так далее.

---

## Этап 1: Последовательная событийная имитация (Текущий статус)

На данном этапе реализована **однопоточная версия** симуляции. Параллелизм поведения сущностей (танков, орудий, снарядов) имитируется путем их последовательного опроса в главном цикле программы (event-driven simulation), что характерно для классических пошаговых стратегий.

### Реализованный функционал (ДЗ1)
- **Архитектура:** Разделение на модель (`sim.c`) и контроллер (`main.c`). Единое состояние мира `World` передается по указателю.
- **Имитация параллелизма:** Главный цикл `while` последовательно вызывает `update_tanks()`, `update_guns()`, `update_shells()`.
- **Системный ввод-вывод:** Вывод на консоль реализован через системный вызов POSIX `write()` (обертка `my_print`), а не через стандартный `printf`.
- **Обработка сигналов:** Корректный перехват `SIGINT` (Ctrl+C) через `signal_handler` с сохранением состояния и лога перед выходом.
- **Баллистика и инварианты:** Снаряд поражает клетку поля в момент разрыва. Уничтоженный танк становится препятствием (`CELL_WRECK`).
- **Логирование:** Автоматическое сохранение итоговой статистики и причины завершения в файл `tankfire.log`.
- **Визуализация:** Отрисовка карты с использованием ANSI escape-последовательностей для очистки экрана.
